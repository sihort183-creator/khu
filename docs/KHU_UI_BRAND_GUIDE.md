## 3. 서체

공식 UI 페이지에는 전용 서체가 명시되어 있지 않다. 공식 홈페이지 CSS(base.css, common.css)에서 실제로 쓰는 스택:

```text
본문:  'Roboto', 'Noto Sans KR', 'Arial', AppleGothic, 'dotum', sans-serif
제목/강조(세리프): 'Merriweather', 'Noto Sans KR', ...
```

색상표 이미지의 숫자 표기도 Roboto Condensed 계열이다. 따라서 서비스 UI 서체는 **Noto Sans KR(국문) + Roboto(숫자·영문)** 를 기본으로 하고, 세리프 강조가 필요하면 Merriweather를 쓰면 공식 톤과 일치한다.

홈페이지 CSS에서 확인되는 기타 값: 본문 텍스트 `#333333`, 링크 포커스 하이라이트 `#14adea`.

## 4. 통합 공지 서비스에 적용할 때의 원칙 (제안)

- **Kyung Hee Red `#A40F16`** 를 브랜드 포인트(로고, 주요 버튼, 활성 탭, 강조)로만 쓰고 면적을 넓게 칠하지 않는다. 공지 목록은 정보 밀도가 높으므로 배경은 흰색/연회색, 텍스트는 `#333333` 계열.
- **Kyung Hee Blue `#0D326F`** 는 링크·정보성 배지·헤더 텍스트 등 두 번째 강조색.
- **Gold `#C0A353`** 는 마감 임박/D-day 같은 특별 강조에 절제해서 사용.
- **Cool Gray `#717171` / Silver `#B5B5B5`** 는 메타 정보(출처·날짜), 구분선, 비활성 상태.
- 공식 휘장·교표는 학교 공식 매체로 오인될 수 있으므로 서비스 로고에 그대로 쓰지 않는다. 캐릭터마크(사자)나 그래픽 모티브 A/C를 보조 그래픽으로만 검토하되, 비공식 서비스임을 명시한다.
- 워드마크·캐릭터마크는 가로 10mm(약 38px @96dpi) 미만 금지 규정을 지킨다.
