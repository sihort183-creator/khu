# 화면 배포 준비

작성 시점: 2026-09-07 02:00 KST. **아직 배포하지 않았다.** 배포에 필요한 것을 다 만들어 두고,
사용자만 할 수 있는 한 가지 때문에 멈춘 상태다. 이 문서는 그 한 가지와 이후 순서를 적는다.

---

## 1. 지금 어디까지 되어 있나

| 조각 | 상태 |
| --- | --- |
| 수집 | 돌고 있다 (GitHub Actions) |
| 저장 | Supabase Postgres + Cloudflare R2 |
| 조회 서버 (`worker/`) | **떠 있다.** `https://khu-notice-api.khu-notice-sihort.workers.dev` |
| 본문 그림 중계 | 코드와 검사는 끝났다. **조회 서버를 다시 배포해야 살아난다.** |
| 화면 (`frontend/`) | **어디에도 올라가 있지 않다.** 빌드·검사는 통과한다 |
| 배포 수단 | 만들어 두었다. 손으로 눌러야만 돈다 |

## 2. 막혀 있는 것 — 사용자만 할 수 있다

**Cloudflare API 토큰이 없다.** 저장소 비밀값에도 없고 이 컴퓨터에도 없다.
토큰은 Cloudflare 계정 소유자만 발급할 수 있으므로 여기서 대신 만들 수 없다.

발급 방법:

1. Cloudflare 대시보드 → 오른쪽 위 계정 아이콘 → **My Profile** → **API Tokens** → **Create Token**
2. **Edit Cloudflare Workers** 템플릿을 고른다. 계정은 이 프로젝트가 쓰는 계정을 고른다.
3. 만들어진 토큰 값을 복사한다. **다시 볼 수 없으니 이때 복사한다.**
4. 아래 명령으로 저장소에 넣는다.

```bash
gh secret set CLOUDFLARE_API_TOKEN --repo sihort183-creator/khu
```

토큰 값은 이 문서나 대화에 붙여넣지 않는다. 위 명령이 물어볼 때만 입력한다.

## 3. 토큰이 들어온 뒤 순서

### 3.1 조회 서버 먼저 (본문 그림 중계를 살린다)

```bash
gh workflow run deploy-worker.yml --ref main
```

배포 뒤 워크플로가 스스로 확인한다 — 학교 밖 주소를 중계하지 않는지(404 여야 한다).

### 3.2 화면 빌드만 먼저 확인

```bash
gh workflow run deploy-web.yml --ref main
```

기본값이 **빌드만 하고 배포하지 않는다.** 결과가 초록이면 다음으로 간다.

### 3.3 화면 배포

```bash
gh workflow run deploy-web.yml --ref main -f deploy=true
```

끝나면 `khu-notice-web` Worker 주소가 나온다. 그 주소로 들어가 4절을 확인한다.

## 4. 배포 직후 확인할 것

- 공지 목록에 **실제 공지**가 뜨는가. 가상 데이터가 뜨면 `KHU_PUBLIC_API_BASE` 변수가 빈 것이다.
- 포스터만 있는 공지의 목록에 **그림이 보이는가.** 안 보이면 조회 서버가 아직 옛 판이다(3.1 을 먼저 한다).
- 공지 상세에서 본문 그림이 보이는가. 브라우저 콘솔에 mixed content 경고가 없어야 한다.
- 화면 폭을 좁혀 휴대폰 크기에서 깨지지 않는가.

## 5. 왜 이 방식인가

- **Cloudflare Workers 로 올린다.** 수집·저장·조회가 이미 Cloudflare 와 Supabase 위에 있어
  청구지를 늘리지 않는다. 무료 한도 안에서 돈다.
- **Vercel 은 고르지 않았다.** 무료(Hobby) 등급은 상업적 이용을 허용하지 않는데
  화면에 광고 자리(`frontend/src/components/Ad.tsx`)가 이미 있다. 나중에 문제가 된다.
- **정적 내보내기로는 안 된다.** 공지 상세 주소(`/notices/<id>`)를 미리 다 만들 수 없다.
  공지가 계속 늘기 때문이다.
- **`next-on-pages` 가 아니라 OpenNext 다.** 앞의 것은 Next 15.5 까지만 지원하는데
  이 프로젝트는 Next 16 이다.
- **OpenNext 는 Windows 에서 빌드되지 않는다**(공식 경고이며 실제로 조용히 멈춘다).
  그래서 빌드를 리눅스 러너에서 한다. 사용자 컴퓨터에서 빌드하지 않는다.

## 6. 아직 정하지 않은 것

- **도메인.** 지금은 `*.workers.dev` 주소로 뜬다. 따로 산 주소를 붙일지는 정하지 않았다.
- **광고를 실제로 넣을지.** 자리만 있고 내용은 없다.
- **조회 서버와 화면을 한 주소로 묶을지.** 지금은 서로 다른 주소다. 묶으면 중계 경로가
  같은 출처가 되어 더 단순해지지만, 지금 구조로도 동작한다.
