# 바로가기 카드 설계 (2026-09-14)

학생이 검색했을 때 **공지 목록 위에 답을 바로 띄우는 카드**. 정부24 방식이다.

이 문서는 2026-09-14 논의와 실측을 정리한 것이다. 아직 **아무것도 만들지 않았고**, 화면 코드
두 건(검색 수정)만 커밋되어 있다. 배포는 하지 않았다.

---

## 1. 왜 필요한가

공지는 "학교가 알리고 싶은 것"이다. "휴학 어떻게 해요" 같은 제도는 게시판에 뜰 이유가 없다.
공지 24,289건의 제목을 세어 보면 그 구멍이 그대로 드러난다.

| 공지가 넘치는 것 | 건수 | | 검색해도 빈손인 것 | 건수 |
| --- | ---: | --- | --- | ---: |
| 채용 | 5,391 | | 휴학 | 81 |
| 모집 | 4,247 | | 전과 | 75 |
| 인턴 | 1,707 | | 졸업요건 | 22 |
| 장학 | 1,106 | | 증명서 | 20 |

분류별로도 같다. **취업·인턴이 33.2%(8,072건)**, 생활 4.0%, 졸업 2.7%.

두 번째 증거: 학생이 **"학점포기제도"** 를 검색하면 `학점포기제도 개선 안내` 같은 공지 5건만
나오고 **정작 "졸업 전까지 6학점까지 포기 가능"이라는 내용은 어디에도 없다.**

이 구멍은 공지를 더 모아서는 절대 메워지지 않는다.

## 3. 카드는 세 모양

### 1형 — 학교 페이지로 바로

그 주제만 다루는 고유 페이지가 있을 때. 도착하면 바로 본문이 보인다.

```
┌─ 휴학 신청 ────────────────── 학사정보 › ─┐
│ 신청 절차와 기간 제한                      │
│ 자주 묻는 질문 7개도 함께 →                │
└──────────────────────────────────────┘
```

### 2형 — 카드 안에서 답을 말해주기

한 페이지에 62개 학과가 몰려 있는 졸업학점표가 여기 해당한다. 링크만 걸면 학생이 표에서
자기 학과를 눈으로 찾아야 한다.

```
┌─ 졸업학점 ──────────────────────────┐
│ 학번을 알려주시면 정확히 찾아드립니다        │
│ [ 2023 ]  경영대학 경영학과 ▾              │
│ ─────────────────────────────────  │
│ 졸업 130학점 · 전공(단일) 63학점            │
│   전공기초 12 · 전공필수 18 · 전공선택 33    │
│ 2023학년도 기준 · 원문 표 보기 ›            │
└──────────────────────────────────┘
```

**학번은 이 카드 안에서만 묻는다.** 가입도 설정도 아니다. 한 번 넣으면 기기에 저장되고
서버로 보내지 않는다. 안 넣으면 최신 학년도 기준으로 보여주고 그렇게 밝힌다.

### 3형 — 우리 공지 중 정확한 한 건을 지목

학과가 매 학기 올리는 것. 외부로 내보내지 않고 그 공지로 보낸다.

```
┌─ 우리 학과 졸업 공지 ────────────────┐
│ 2026-1학기 졸업대상자 자격증 제출 안내  3/25 › │
│ 2026학년도 졸업논문 계획서 제출 안내   3/25 › │
└──────────────────────────────────┘
```

## 4. 자료가 어디서 오나

| 자료 | 쓰임 | 상태 |
| --- | --- | --- |
| 학사정보 웹 64개 | 제도 본문 | **31개 깨끗 / 12개 카드 금지** |
| E-Book 140쪽 | 웹이 틀린 곳의 기준본 | 확인됨. **링크로는 못 씀** |
| 졸업학점표 13개(HTML 표) | 학과별 학점 | 126행 중 112행이 E-Book과 일치 |
| 단과대 시행세칙 | 학과별 졸업요건 | **외대 1곳만 확인. 21곳 미확인** |
| 우리 공지 24,289건 | 학과 공지 지목 | 있음 |

### 4.1 E-Book은 링크 대상으로 쓸 수 없다

학교 E-Book 페이지(`menuNo=21200075`)에 실제로 가보면 **iframe이 PDF를 렌더하지 못해
빈 화면**이다. "새창열기"를 눌러도 **5.4MB 파일이 다운로드**된다. `#page=109` 를 붙여도
서버가 첨부파일로 내려보내 뷰어가 안 뜬다.

→ **내용은 E-Book 기준, 링크는 웹 HTML 페이지로.**

### 4.2 단과대 시행세칙 — 22곳 전수 조사 (2026-09-14)

단과대는 **서울 13 + 국제 9 = 22곳**이다(학사정보 「학과편제표」 첨부 PDF에서 셈. 무용학부·
자율전공학부·자유전공학부는 '학부'라 빠진다. `organizations.json` 의 `type=college` 56행은
대학원·연구소가 섞여 못 쓴다).

**17곳 확인 · 3곳 부분 · 2곳 못 찾음.**

| 형태 | 곳 |
| --- | ---: |
| 단과대 통합 PDF | 5 |
| 학과별 분리 PDF | 5 |
| 게시판 글 | 6 |
| HTML 조문 | 3 |
| 없음 | 2 |

**못 찾은 곳** — 응용과학대학(사이트가 통째로 "준비중"), 간호과학대학(조문 문서 없이 HTML
이수학점 표만). **부분** — 치과대학(학부판 본문이 비어 대학원판만), 약학대학(시행세칙 메뉴
4개가 전부 빈 페이지, 실체는 '운영내규' `3900158/159/161`), 국제대학(PDF가 `com.khu.ac.kr/upload/`
— robots 금지라 안 받음). **이 다섯은 학과 사무실로 보내는 수밖에 없다.**

#### 세 질문에 대한 답

**전교 통일 서식인가 — 아니다.** 조문 *내용*은 세 갈래로 수렴하나(외대형 / 경영대처럼 앞부분을
잘라낸 형 / 미술·약학·치과처럼 아예 다른 형) *형태*는 위 표처럼 제각각이다.

**기계로 뽑을 수 있는가 — 된다.** 22곳 중 **11곳은 주소가 고정**이라 최신판을 자동 추적할 수
있고, 조문은 `제N조(제목)` 꼴로 규칙적으로 뽑힌다. 짚을 곳은 **(졸업이수학점)·(전공이수학점)·
(졸업논문)** 세 조문.

> **조 번호로 찾으면 안 된다.** 졸업논문이 공과대 제10조, 외대 제11조, 호텔관광 제7조이고
> 문과대는 아예 독립 조문이 아니라 **제9조(기타과목 이수) ② 항**에 들어 있다.
> **괄호 안 제목으로 찾아야 한다.**

**주소가 매년 바뀌는가 — 절반만.** 게시판형·고정 menuNo형 13곳은 그대로고, 연도 탭을 쓰는
9곳(외대·예디·미술·생활과학·경영PDF·국제·의과·치과·음악)만 해마다 새 주소가 생긴다.
대부분 3월 1일 시행이므로 **매년 3월 중순에 9곳만 확인**하면 된다.

#### 학과마다 졸업요건이 진짜로 다르다

| 학과 | 졸업학점 | 졸업논문 자리에 무엇이 |
| --- | ---: | --- |
| 외국어대 스페인어학과 | 120 | 어학자격증 DELE B1 이상 (캡스톤 대체 가능) |
| 경영대 경영학과 | 120 | **졸업시험** — 또는 현장실습·CPA·논문게재·수상·창업 |
| 문과대 국어국문학과 | 120 | 논문 + 문과대 공통 '인문학과진로탐색' 이수 |
| 공과대 원자력공학과 | **130** | 논문·원자력기사 등 자격증·현장실습 4주·원자력캡스톤디자인·설계과목 3과목 중 1 |
| 공과대 산업경영공학과 | — | '창의적종합설계1 또는 2' 이수 시 논문 통과 인정 |
| 공과대 화학공학과 | — | **지정 학회 8곳에 게재**한 경우만 인정 + 졸업논문통과신청서를 기말고사 전일까지 학과사무실 제출 |

전교 공통 안내("8학기 이상, 평점 1.70 이상")로는 학생이 아무것도 알 수 없다. **학과별 카드가
필요한 근거가 이것이다.**

#### 학과 카드에 담을 것

```
졸업이수학점        120 / 130 …
전공이수학점        단일 · 다전공 · 부전공
전공 영역별 의무    예) 스페인어학과 문화지역학 2과목 + 문학 2과목
졸업논문 + 대체조건  ← 학생에게 가장 실용적인 칸. "논문 안 써도 되는 길"이라 빠짐없이 싣는다
어학·자격증         DELE B1 / SNULT 3+급 / FLEX 776·200·200 …
편입생 규정
```

#### 외국어대학 (기준 사례)

시행세칙 184쪽, 조문 193개. **9개 학과가 똑같은 틀을 반복**한다.

```
학과마다 있는 조문 (1~17조)
  교육목적 · 일반원칙 · 졸업이수학점 · 전공이수학점 · 교양이수학점
  부전공이수학점 · 편입생 전공이수학점 · 졸업논문 · 영어강의 의무이수
  SW기초교육 · 교환학생 학점인정 · 대학원과목 이수 · 타전공과목 인정
  마이크로디그리 · 교직과정 · 외국인학생 한국어능력
부칙: 시행일 33회 · 경과조치 17회   ← 학번별 예외가 여기
```

**조문 제목 전체를 훑었으나 휴학·복학·전과·재입학·재수강·학점포기·학점세이브·수강신청·
등록금·장학은 한 건도 없다.** 그래서 두 문서가 역할을 나눈다.

| 시행세칙 | E-Book |
| --- | --- |
| 졸업 · 전공/교양/부전공 이수학점 · 편입생 | 학적변동(휴학·복학·제적·전과·재입학) |
| 학점인정(교환학생·대학원·타전공) | 성적제도(재수강·학점포기·세이브) |
| 교직 · 마이크로디그리 · 외국인 한국어 | 수강신청 · 등록금 · 장학 · 계절수업 |
| 학번별 경과조치 | |

서로 겹치지 않아 한 카드 안에서 부딪히지 않는다. 다만 **영어강의 의무이수·SW기초교육**은
양쪽에 다 있다(전교 공통을 학과가 다시 적음). 이때 판별 기준은 "같은 주제냐"가 아니라
**"값이 같으냐"** 여야 한다. 학과가 전교 기준보다 엄격할 수 있고, 그걸 "겹친다"고 지우면
학생이 졸업을 못 한다.

```
같은 주제 + 같은 값  →  지움
같은 주제 + 다른 값  →  보여줌 ("우리 학과는 4과목")
학과에만 있음       →  보여줌
```

### 4.3 스페인어학과 실례

```
제11조(졸업논문)
  졸업논문 심사 통과. 마지막 학기에 수강신청.
  심사 전 어학자격증 제출 — DELE B1 이상 / SNULT 3+급 이상 /
  FLEX 세 분야 2A 이상(듣기·읽기 776, 쓰기 200, 말하기 200) 중 택1
  '캡스톤디자인 히스패닉세계연구' 이수 시 대체 가능
제12조  문화지역학 2과목 + 문학 2과목 의무 이수
```

같은 내용이 **우리 공지에도 이미 들어와 있다**(`[중요] 2026-1학기 졸업대상자 자격증 제출
안내`, 학과 행정실 031-201-2232). 다만 시행세칙이 더 자세하다 — 공지에는 "FLEX 세분야 2A"
까지만 있고 실제 점수와 캡스톤 대체는 시행세칙에만 있다.

**반대로 학사일정은 웹이 최신이다** — 2026년 신설 제헌절 공휴일이 웹에만 반영돼 있다.
어느 쪽이든 **날짜를 카드에 박으면 안 되고** 링크로 보낸다.

### 5.2 카드 금지 명단 12개

```
휴학 · 수강신청일정 · 학점재수강 · 복수학위 · 사회혁신학기제 · 졸업
학석사연계 · 조기졸업 · 학사일정2026 · 서울2026 구조표 · 국제2026 구조표 · 학적사항정정
```

규칙으로 뽑으면 안 되고 손으로 쓰거나 E-Book 기준으로 써야 한다.

**나머지 31개 산문 페이지는 숫자가 한 건도 어긋나지 않았다.** 수강허용학점은 14개 행과
주석까지, 학점교류는 대학별 조건 표 전체가 일치했다.

### 5.3 자동 요약이 틀리는 3개는 스스로 틀린 줄 모른다

64개에서 요약 첫 줄을 뽑는 규칙을 만들면 학점교류·수강신청일정·수강신청시스템 셋이
엉뚱한 줄을 고른다(첫 문장이 정의가 아니라 대학 이름 나열이거나 표). 문제는 **이 셋이
"잘 뽑았다"고 스스로 보고한다**는 점이다. 걸러내는 규칙을 넣으면 제적·조기졸업의 멀쩡한
요약이 같이 죽는다. → **명단을 박아 사람이 쓰는 수밖에 없다.**

### 5.4 졸업능력인증은 대부분 폐지됐다

전교 안내(학사정보 `21200029`, E-Book 100쪽, 2013년자 운영지침)는 제도가 살아 있다는
전제로 신청기간·절차까지 설명한다. 실제로는:

| 단과대 | 상태 |
| --- | --- |
| 공과대학 | 2022학년도 폐지 |
| 이과대학 | 2022학년도 폐지 |
| 외국어대학 | 2024학년도 폐지 (이전 학번 소급) |
| 음악대학 | 2003학번 이후 미적용 |
| 문과·정경·경영 | 시행세칙에 언급 자체가 없음 |
| 약학대학 | 운영 중 (어학 점수 아닌 비교과 3개 영역) |
| 나머지 12곳 | 확인 못 함 (총 22곳 중 9곳 + 1개 학과만 확인) |

게다가 검색하면 **이과대 구 기준(TOEIC 700) 페이지가 먼저 뜨고**, 지리학과는 소속 단과대가
폐지했는데도 2011년자 기준을 아직 띄우고 있다. **학교 안에서도 정보가 어긋나 있다.**

→ **졸업능력인증은 값을 보여주면 안 된다.** "단과대마다 다르고 폐지한 곳이 많다"고 밝히고
행정실 연락처로 보낸다. 연락처는 이미 983건 갖고 있다(학과 사무실류 213건).

### 5.5 졸업요건과 졸업능력인증은 다른 제도다

```
졸업능력인증제   단과대가 정함 · 대부분 폐지
학과 졸업요건    학과가 정함 · 살아 있음 · 졸업논문 요건에 붙어 있음
                스페인어학과 DELE B1 / 프랑스어학과 DELF B1
```

2026학년도 외국어대학 요약표에 "5. 졸업능력인증제 — 폐지"와 "6. 졸업논문 — 학과가 규정한
기준에 충족"이 **나란히 별개 항목**으로 있다.

### 5.6 제도가 개정되면 우리 내용이 낡는다

학점포기제도는 4개월 새 개정·개선 안내가 4건 올라왔다(8/4, 8/7, 9/1, 9/3).
**그 신호가 우리 손에 이미 있다** — 같은 주제 공지가 최근에 올라왔다는 것 자체가 신호다.

```
⚠ 이 제도는 최근 안내가 올라왔습니다 — 9/3 개정 안내 확인 ›
```

제도 내용은 바로 보여주되, 최근 공지가 있으면 같이 짚어준다.

### 5.7 확인 필요

**식품영양학과 졸업학점 — 웹 표 120 vs E-Book 130.** 나머지 13개 값은 완전히 일치하는데
한 칸만 어긋난다. E-Book 44쪽 각주가 "이 표는 2025학년도 시행세칙 근거"라고 밝히고 있어
E-Book 우선 원칙을 그대로 쓸 수 없다. **시행세칙의 "졸업이수학점" 조문이 정본이다.**

### 5.8 괄호 안 조건을 떼면 안 된다

시행세칙 조문에는 **적용 대상 조건이 붙어 있는 것이 많다.**

```
SW 기초교육 6학점      (편입생, 순수외국인 및 재직자 특별전형자 제외)
영어강의 3과목         (단, 편입생은 1과목)
한국어능력 TOPIK 4급   한국어트랙 외국인 학생        ← 한국 학생과 무관
```

마지막 것은 실제로 잘못 옮긴 적이 있다(2026-09-14). 조사 보고에 "원자력공학과는 TOPIK 4급까지
붙는다"고 적혔는데, 원문은 **제13조(외국인 학생의 한국어 능력 취득)** 이고 대상은 "한국어트랙
외국인 학생"이다. 게다가 학과 고유 요건도 아니다 — 기계·산업경영·화학공학과에 같은 문장이
있고 외대 9개 학과에도 전부 있는 **전교 공통 조문**이다.

> **규칙: 대상 제한(편입생·외국인·학번·트랙)이 붙은 조문은 조건을 함께 보여주거나, 아예
> 싣지 않는다.** 조건을 떼고 숫자만 보여주면 편입생이 SW 6학점을 들어야 하는 줄 알고,
> 한국 학생이 TOPIK을 준비한다.

5.1의 졸업 페이지 문제("2026학년도 입학생부터 적용"이 빠져 다전공 의무가 전원에게 걸리는
것처럼 읽힘)와 정확히 같은 종류다.

## 6. 부하 — DB를 안 거치는 것이 조건

지난 두 사건은 **둘 다 "DB를 읽고 쓰는 경로"** 에서 났다.

| | 1차 (2026-09-09) | 2차 (2026-09-13) |
| --- | --- | --- |
| 무엇 | DB egress 월 5GB 초과 | 디스크 IO 예산 고갈 |
| 원인 | 공개 파일 만들 때 공지 본문 통째 재읽기(회차당 143MB) | 거대한 `IN` 목록이 감시 수집기 임시 파일을 회차당 9.3GB로 부풀림 |

**학생이 화면을 보는 경로에서는 한 번도 나지 않았다.** 거긴 DB를 안 타기 때문이다.

### 지켜야 할 두 가지

1. **바로가기 자료를 DB에 넣지 않는다.** 저장소 파일 → R2 직행. 연락처(983건)처럼 DB에
   적재하면 회차마다 읽고 내보내는 대상이 하나 더 늘고, **그게 정확히 1차 사건의 경로다.**
2. **기존 파일에 얹는다.** 화면이 어차피 받는 `catalog.json`(751바이트)에 항목 목록을 합치면
   **학생당 추가 요청이 0건.** 졸업학점표만 별도 파일로 두고 **졸업 카드가 실제로 떴을 때만**
   받는다.

### 크기 (실측)

| | 원본 | gzip | 색인 한 조각(103KB) 대비 |
| --- | ---: | ---: | ---: |
| 학사정보 64개 카드 요약 | 36,221 B | **9.6 KB** | 9% |
| 64개 본문 전체 | 240,246 B | 47.2 KB | 46% |
| 구조화 전체 | 308,363 B | 52.9 KB | 51% |

참고 수치: 공지 24,289건 · 검색 색인 2,000건당 gzip 103KB(원본 520KB) · 13조각 약 1.3MB ·
캐시 1년 `immutable`.

**수집 요청 증가**: 졸업학점표 연 1회 13페이지, 단과대 시행세칙 연 1회 22개, 메뉴 트리
하루 1페이지. 회차마다 도는 것이 아니다.

## 8. 아직 안 정한 것

1. **얇은 12개 + 틀린 3개, 총 15개를 손으로 쓸까**
2. **원문이 틀린 곳은 그 항목만 빼고 링크로 보낼까**
3. **단과대 시행세칙에서 학과별 졸업요건을 실제로 뽑아내는 작업** — 조사는 끝났다(4.2).
   119개 학과분을 뽑되, 형태가 다섯 갈래라 한 규칙으로는 안 된다. 문서를 못 찾은 5곳
   (응용과학·간호과학·치과·약학·국제)은 학과 사무실 연락처로 보낸다
4. **식품영양학과 졸업학점 120 vs 130** — 시행세칙으로 확인
5. **2025-01-01 이전 고정 공지 83건 중 상시 규정** 추려낸 목록을 어떻게 쓸까
6. **조직 중복 29곳** — 같은 이름인데 경로 깊이가 다른 짝. 한쪽에만 공지가 붙는다
7. 가운뎃점 정규화 — 원문에 `･`(U+FF65) `·` `∙` `・` 가 섞여 있어
   `학석사연계`로 검색하면 `학･석사연계`가 안 잡힌다. 우리 공지에도 3종이 섞여 있다
