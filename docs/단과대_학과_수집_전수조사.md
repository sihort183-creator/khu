## 6. 화면 — "공지가 없어도 목록에는 있어야 한다"는 요구는 지금 지켜지지 않는다

사용자 요구는 **"단과대는 공지가 아예 안 올라와도 목록에는 있어야 한다"**였다.
현재 코드는 그렇지 않다. (프런트엔드 파일은 고치지 않았다. 사실만 적는다.)

- 숨기는 자리: `frontend/src/components/OrganizationPicker.tsx:77` 과 `:82`.
  `77` 줄이 **"붙은 게시판 수가 0 이고 공지 수도 0 이면 지운다"**로 판정하고,
  `82` 줄이 **자식도 안 남고 자기도 조건 미달이면 트리에서 아예 뺀다.**
- **단과대 예외는 없다.** 학과와 같은 규칙을 받는다.
- 기본값은 숨김이다(`:43` `useState(false)`). 화면 아래 **"아직 공지가 없는 N곳 더 보기"**
  버튼을 눌러야 나온다.
- 백엔드는 아무것도 거르지 않는다(`backend/app/export/static.py:752`, `is_active` 만 본다).
  **자료는 화면까지 다 도착한다. 감추는 것은 화면이다.**

이 규칙으로 **기본 화면에서 사라지는 단과대는 13곳**이다.

| 기본 화면에서 사라지는 단과대 13곳 |
| --- |
| 경영대학 · 교육대학원 · 대 학 원 · 동서의학대학원 · 법과대학 · 법무대학원 · 아트·퓨전디자인대학원 · 의과대학 · 의학전문대학원 · 체육대학 · 체육대학원 · 치의학전문대학원 · 테크노경영대학원 |

- `전자정보대학`·`소프트웨어융합대학`은 자기 출처가 0 이지만 **하위 학과에 출처가 있어 살아남는다.**
- `정경대학`은 출처 4개가 전부 폐쇄인데도 **개수는 4로 세어져 목록에는 남는다.**
  다만 **골라도 공지가 0건**이다. 판정이 상태를 보지 않기 때문이다(`sources.status` 를 안 본다).
- 학과 70곳은 전부 사라진다.

그리고 홈 화면(`/`)은 조직을 고르면 **하위 학과 공지를 합쳐 주지 않는다**
(`frontend/src/lib/api.ts:450-461`, 선택 조직과 그 **상위**만 포함). 전체 목록(`/all`)은
합쳐 준다(`api.ts:414-425`). 그래서 "단과대를 골랐는데 아무것도 안 나온다"가 홈에서 먼저 보인다.
