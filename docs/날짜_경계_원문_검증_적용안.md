# 날짜 경계 원문 검증과 운영 적용

## 정본과 적용 경로

운영 설정의 정본은 DB의 활성 출처 설정 버전이다. 최초 등록용 `registry/bootstrap/sources.json`을 바꿔도 운영에는 자동 반영되지 않는다. 이번 작업은 실제 원문 전체 목록을 읽고 증거를 저장한 뒤, 통과한 출처만 새로운 운영 설정 버전을 만드는 경로를 추가했다.

## 실제 확인

- 공학교육혁신센터 공통 CMS: 공식 화면에서 페이지당 10·20·30·40·50개 선택을 제공한다. 50개 요청으로 전체 10페이지 일반 글 489건을 확인했다. 일반 글 날짜는 2026-07-20부터 2006-04-27까지 역전 없이 내려간다. 고정 공지는 날짜 검사에서 분리하고 수집에서는 계속 포함한다.
- 위 원문의 마지막 10쪽은 일반 글 39건, 전체 건수 표시 489건이다. 수정된 다음 페이지 검사도 끝으로 판정하며 다음 11쪽 링크가 없다. 검증 후 날짜 경계를 적용하면 첫 페이지에 기간 내 글이 있고 2쪽은 모두 기간 밖이므로 2쪽에서 초기 범위를 마칠 수 있다.
- 그누보드 `afd-05_02`도 실제 전체 목록 날짜 검증을 통과했다. 공식 그누보드 서버 코드는 `sst=wr_datetime&sod=desc`(작성일 내림차순)를 지원한다. 요청에 이를 명시하며 실제 출력 전체를 추가 검증한다.
- 공통 CMS 원문에서는 날짜 구간 검색이나 날짜 정렬 지정 기능을 확인하지 못했다. 제목·내용 검색을 날짜 검색인 것처럼 사용하지 않는다.

로컬 원문 증거는 `backend/.localstore/date-order-live-abeek.json`, `backend/.localstore/date-order-live-afd.json` 및 동일 이름의 폴더에 저장했다. 운영 전체 검증은 별도 실행이 필요하다.

## 검증 정책

몇 페이지 표본만으로 날짜 정렬을 허용하지 않는다. 모든 일반 글의 날짜가 확정되고, 전체 목록의 날짜가 내림차순이며, 실제 끝까지 도달하고, 반복 페이지·중복 일반 글이 없을 때만 경계 종료를 제안한다. 날짜 미상·역전·페이지 제한·통신 실패 출처는 통과 처리하지 않는다.

제안의 유효기간은 검증 종료부터 12시간이다. 영구적인 서버 정렬 계약으로 간주하지 않는다. 실행 중 날짜 미상이나 역전을 발견하면 새 설정 버전으로 날짜 정렬 가정을 폐기하고 전체 탐색으로 계속 진행한다. 이후에도 같은 잘못된 가정이 다시 켜지지 않는다.

페이지 크기나 정렬 변경 시 기존 페이지 위치와 완료 표시를 초기화한다. 기존 공지 데이터는 유지한다. 적용 파일의 원래 설정 지문과 현재 설정이 다르면 전체 적용을 중단한다. 검증 파일은 원문 증거와 함께 보존한다.

공통 CMS의 숫자 페이지 묶음 마지막에서 다음 묶음 링크를 놓치던 문제도 수정했다. 실제 링크의 목표 쪽을 읽는다. 적용 시 이전 방식에서 10쪽 배수에 전체 종료로 완료 처리된 출처는 검증 통과 여부와 관계없이 다시 확인하도록 완료 표시를 취소한다.

## 운영 명령

수집 실행과 같은 동시 실행 제한 아래에서 진행한다. 운영 DB와 저장소 자격 증명은 기존 환경변수로만 읽는다.

```powershell
python -m app.ops.date_order audit --max-pages 300 --concurrency 12 --output .localstore/date-order-production.json
python -m app.ops.date_order apply --output .localstore/date-order-production.json
```

감사는 운영 DB를 변경하지 않는다. 적용은 검증된 출처의 설정 새 버전과 범위 재검증 상태만 저장한다. 미통과 출처를 일괄 날짜순으로 바꾸지 않는다. 전체 370개가 실제로 통과하는지는 운영 원문 감사 결과로 판단해야 한다.

## 한계

전체 목록 검증에도 원문이 검사 도중 바뀔 수 있다. 반복 번호·날짜 역전은 이를 감지하는 방어 장치이며 서버의 일관된 시점 보장은 아니다. 미래에 원문 작성일을 임의로 바꾸는 것까지 영구적으로 증명하지 않는다. 유효기간이 지나면 다시 원문을 검증해야 한다.
