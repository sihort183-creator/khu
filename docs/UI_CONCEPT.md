## 0. 차별점 확인 (조사 결과)

- 경희대 공식 통합앱(2024, 하나은행 지원)에는 "MY전공 → 학과/전공 홈페이지 연결" 기능이 있지만 **단순 링크**다. 공지를 모아 보여주지 않는다.
- 에브리타임은 커뮤니티 중심이라 공식 공지가 체계적으로 모이지 않는다.
- 따라서 이 서비스의 화면은 **"공지 피드"** 하나에 집중한다. 커뮤니티·시간표·학생증 등은 만들지 않는다.

---

## 1. 디자인 원칙

1. **피드가 곧 서비스다.** 첫 화면 = 내 공지 피드. 온보딩 3탭 외에는 아무 것도 가로막지 않는다.
2. **스캔 가능성.** 학생은 제목만 훑고 넘긴다. 카드 1장 = 제목 + 배지 1줄 + 메타 1줄. 본문 미리보기는 기본 접힘.
3. **그냥 공지 페이지다.** 로그인 없음. "마지막 방문 이후 새 공지" 배너와 "마감 임박" 섹션은 만들지 않는다(2026-09-06 결정). 새 글은 게시판처럼 제목 옆 작은 N 표시만.
4. **게시판 구조, 부드러운 표면.** 구조는 에브리타임 웹처럼 1px 테두리 박스 안의 목록 행. 표면은 모서리 10px, 아주 옅은 그림자, 따뜻한 회색 배경(#F6F5F2)으로 다듬는다. 배경 패턴·등장 애니메이션·이모지·큰 그라데이션은 쓰지 않는다. 색은 공식 팔레트(Red #A40F16, Blue #0D326F, Gold #C0A353)를 쓰고, 헤더 최상단 4px 라인은 Gold·Red·Blue 스트라이프. 로고 텍스트 "경희공지"는 Blue. Red는 활성 탭, N 표시, 주 버튼에만. (v0.2의 2px 각진 스타일은 "너무 옛날 웹" 피드백으로 폐기, 2026-09-06)
5. **로그인 없음(MVP).** 학과 설정·구독·읽음 상태는 브라우저 localStorage. 나중에 계정 동기화 추가.
6. **모바일 우선.** 대부분 폰으로 본다. 데스크톱은 같은 피드를 3열 레이아웃으로 확장.

### 어두운 판 (2026-09-08 추가)

기본은 기기 설정(`prefers-color-scheme`)을 따르고, 바닥글의 "밝게 / 어둡게 / 기기 설정"으로
덮어쓸 수 있다(`localStorage` 저장, `<html data-theme>`). 토큰 한 벌을 `globals.css` 에 더 뒀다.
브랜드 색은 어두운 배경에서 대비가 모자라 밝은 변형을 쓴다 — Red `#EE7A80`(카드 6.04:1),
Blue `#93B6F5`(8.01:1), Gold `#CFAE5F`(7.71:1). 색을 칠하고 흰 글자를 얹는 자리(주 버튼·활성 칩·
캠퍼스 토글)는 `--red-fill #C4242C`(흰 글자 5.78:1) / `--navy-fill #2F5FBF`(5.98:1) 를 따로 쓴다.
주제 배지 11색도 어두운 판이 따로 있고 글자/배경 대비는 모두 6.3:1 이상이다.
원문 그림·포스터는 어두운 판에서도 손대지 않는다.

조직 배지(캠퍼스·단과대·학과)는 색 없이 **회색 외곽선(outline)** 으로 통일해 주제 배지와 시각적으로 구분한다.
출처 유형은 배지가 아니라 **아이콘**(🌐 웹 / Instagram 글리프)으로만 표시한다.

## 3. 화면 구조

### 3.1 온보딩 (최초 1회, 3단계)

```text
[1/3] 캠퍼스     ( 서울 ) ( 국제 )
[2/3] 단과대     리스트(검색 가능)
[3/3] 학과       리스트(검색 가능)   [건너뛰기]
→ "이제 정경대·행정학과 공지를 놓치지 않아요"  [시작하기]
```

건너뛰면 `전체 공지`로 진입하고, 헤더의 "내 학과 설정" 배너가 남는다.

### 3.2 헤더 (모든 화면 공통, 상단 고정)

```text
┌──────────────────────────────────────────────┐
│ 경희공지        [서울 ▾]        🔍   ⚙       │
├──────────────────────────────────────────────┤
│  내 공지  ·  전체  ·  출처  ·  연락처          │  ← 활성 탭 밑줄 Red
└──────────────────────────────────────────────┘
```

- 로고: 공식 대학휘장 + 세리프 텍스트 "경희공지"(Red). 학생 편의 서비스이므로 휘장을 사용하되, 푸터에 "학생이 만든 비공식 서비스" 문구를 둔다(2026-09-06 결정).
- 캠퍼스 토글은 헤더에 항상 노출. 서울/국제 학생이 서로 섞인 공지에서 가장 먼저 걸러내고 싶은 축이기 때문.
- 검색은 제목·본문 전문 검색(PostgreSQL FTS) 화면으로 이동.

### 3.3 내 공지 (홈)

```text
[전체] [학사] [장학] [취업·인턴] [행사] [프로그램] … ▸   ← 주제 칩(2px 모서리), 다중선택, 가로 스크롤

┌ 서울 · 정경대학 · 행정학과 + 구독 4   12건        최신순 | 조회순 ┐  ← 게시판 헤더 줄
│ [학사] 2026-2학기 학점포기 신청 안내 N                           │  ← 주제 라벨 + 제목 + 새 글 N
│ 정경대학 교학팀 | 09.03 | 웹 | 동일 공지 3곳                    │  ← 메타 12px 회색
├──────────────────────────────────────────────────────────────┤
│ [썸네일] [행사] 2026 대동제 부스 참가 단체 모집 N                 │  ← Instagram은 48px 회색 썸네일
│          서울캠퍼스 총학생회 | 09.05 | Instagram                 │
├──────────────────────────────────────────────────────────────┤
│ 광고 ▢ 토익 900+ 4주 특강                                       │  ← 5번째 행 뒤 1개, 라벨 명시
├──────────────────────────────────────────────────────────────┤
│ …                                                             │
│                          더 보기                              │
└──────────────────────────────────────────────────────────────┘
```

- 정렬: 게시일 내림차순. 별도 섹션 없음.
- 행 클릭 → 상세(출처명 상단 바, 주제 라벨, 제목, 메타, 본문, 첨부, 출처 N곳 목록, [원문 보기] 빨간 버튼).
- 동일 공지 N곳: 한 행으로 보여주고 상세에서 출처를 펼친다.

### 3.4 전체 공지

내 공지와 동일한 카드 피드. 차이는 상단에 **조직 필터 바**가 추가된다.

```text
[서울 ▾] [단과대 ▾] [학과 ▾] [기관·사업단 ▾]      ← 드롭다운 4개 + 활성 필터 칩 표시/제거
```

### 3.5 출처

기획서 5.1의 조직 트리를 그대로 탐색·구독하는 화면.

```text
경희대학교
├ 서울캠퍼스            구독 12 / 전체 96
│ ├ 정경대학  ▸
│ │ ├ 행정학과 홈페이지      🌐  ● 15분 전     [구독중]
│ │ └ 행정학과 학생회        ◎  ● 2시간 전     [구독]
│ ├ 미래인재센터              🌐  ● 15분 전     [구독중]
```

- 각 소스 행: 유형 아이콘, 이름과 설명, 마지막 확인 시각(상태 점: 초록/노랑/빨강, 480px 이하에서는 숨김), 구독 토글.
- 소스 탭 → 그 소스의 공지만 보는 피드.
- 상단 검색으로 "SW중심대학" 같은 기관을 바로 찾는다.

### 3.6 연락처 (신규 탭, 2026-09-06 추가)

공지와 별개의 **독립 분류**. 학과 사무실·단과대 교학팀·행정부서·지원센터·학생회·부속기관·사업단의 공개 연락처를 모은다.

```text
[검색: 부서·학과·업무 (예: 장학, 휴학, 기숙사)]
┌ 학과 ──────────────┐ ┌ 행정부서 ─────────────┐
│ 행정학과 사무실       │ │ 학생지원센터 (장학)     │
│ 전화 02-961-0489    │ │ 전화 02-961-0067      │
│ 이메일 / 위치 / 운영시간 │ │ …                     │
│ [전화하기] [홈페이지] [이 기관 공지] │
```

- 사용자의 학과·단과대 연락처를 맨 위에 고정.
- 카드의 "이 기관 공지" 버튼은 해당 소스 피드로 연결해 공지 ↔ 연락처를 오간다.
- 데이터는 각 기관 홈페이지 공개 정보를 수집(백엔드: `CONTACT` 엔티티, ORGANIZATION에 연결). 업무 키워드(휴학, 장학, 기숙사 …)로 검색되도록 태그를 둔다.

### 3.7 설정 (⚙)

캠퍼스/단과대/학과 변경, 구독 목록, 숨긴 출처, 알림(추후: 웹 푸시), 다크모드(추후), 서비스 소개·비공식 안내·문의.

## 4. 데스크톱 레이아웃 (≥1024px)

```text
┌ 헤더 (동일, 최대폭 1180px) ──────────────────────────────────┐
│ 좌측 220px         │ 중앙 목록                  │ 우측 240px  │
```

모바일은 헤더의 탭 줄(가로 스크롤)로만 이동한다. 하단 탭바를 두지 않는다.

## 5. 상태 · 엣지 케이스

- 빈 목록: "표시할 공지가 없습니다" + 설명 한 줄.
- 수집 실패 소스: 출처 화면에 빨간 점 + "3일째 수집 실패". 피드에는 조용히 빠진다.
- 본문 없이 첨부만 있는 공지: 카드에 📎 아이콘과 파일명.
- 아주 긴 제목: 2줄 말줄임.

## 6. 구현 (2026-09-06 완료, `frontend/`)

- 역할 분담: **백엔드는 Codex, 프론트엔드는 Claude**.
- 스택: Next.js 16(App Router) + React 19 + Tailwind v4 + SWR. 서체는 next/font의 Noto Sans KR.
- 데이터 계약: `KHU_API_CONTRACT_DRAFT.md`를 `src/lib/types.ts`로 옮겼고, `src/lib/api.ts`가 `NEXT_PUBLIC_API_BASE`가 비어 있으면 `src/mocks/data.ts`(규격 9절 시나리오 포함)로 동작한다. 실제 서버가 생기면 `.env.local`에 주소만 넣는다.
- 화면: `/`(내 공지, `POST /v1/feeds/preview`), `/all`(전체, `GET /v1/notices` + 단과대/학과/기관/출처 유형 필터 + 검색), `/notices/[id]`(상세), `/sources`(출처 + 구독 토글), `/contacts`(연락처). 온보딩은 첫 방문 시 전체 화면, 헤더 사람 아이콘·우측 "변경"으로 다시 연다.
- 비회원 설정은 localStorage `khu-notice.settings.v1`에만 저장(useSyncExternalStore). 로그인 없음.
- 주제 코드 목록은 `/v1/catalog`에서 오고, 프론트는 코드 → 배지 색만 `src/lib/category.ts`에 가진다.
- 상태 표현: 원문 확인 불가·등록일 미확정·대상 미확정·첨부 다운로드 불가·연락처 확인 오래됨/충돌·출처 갱신 지연/접근 제한/연결 대기·FEED_CHANGED 재조회·빈 결과·오류 재시도·404.
- 애니메이션 컴포넌트가 필요해지면 [SmoothUI](https://smoothui.dev/) (shadcn/ui 기반, `npx shadcn@latest add @smoothui/<component>`)에서 가져온다. 현재는 미사용.
- 정적 목업 `mockup/index.html`은 디자인 참고용으로 남긴다.
