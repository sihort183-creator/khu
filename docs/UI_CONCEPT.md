# 경희공지 UI 구상 (v0.1)

> 2026-09-06 초안. 브랜드 팔레트는 `docs/KHU_UI_BRAND_GUIDE.md` 기준.
> 기획서 `KHU_INTEGRATED_NOTICE_PLAN.md` 5~6장(조직 계층·화면 구조)을 화면 단위로 구체화한 것.

---

## 0. 차별점 확인 (조사 결과)

- 경희대 공식 통합앱(2024, 하나은행 지원)에는 "MY전공 → 학과/전공 홈페이지 연결" 기능이 있지만 **단순 링크**다. 공지를 모아 보여주지 않는다.
- 에브리타임은 커뮤니티 중심이라 공식 공지가 체계적으로 모이지 않는다.
- 따라서 이 서비스의 화면은 **"공지 피드"** 하나에 집중한다. 커뮤니티·시간표·학생증 등은 만들지 않는다.

---

## 1. 디자인 원칙

1. **피드가 곧 서비스다.** 첫 화면 = 내 공지 피드. 온보딩 3탭 외에는 아무 것도 가로막지 않는다.
2. **스캔 가능성.** 학생은 제목만 훑고 넘긴다. 카드 1장 = 제목 + 배지 1줄 + 메타 1줄. 본문 미리보기는 기본 접힘.
3. **"놓친 것"을 먼저 보여준다.** 마지막 방문 이후 새 공지 수, 마감 임박 공지를 상단에 고정.
4. **브랜드색은 포인트로만.** Kyung Hee Red는 로고·활성 탭·주요 버튼에만. 정보 밀도가 높은 화면이라 면은 흰색/연회색.
5. **로그인 없음(MVP).** 학과 설정·구독·읽음 상태는 브라우저 localStorage. 나중에 계정 동기화 추가.
6. **모바일 우선.** 대부분 폰으로 본다. 데스크톱은 같은 피드를 3열 레이아웃으로 확장.

## 2. 디자인 토큰

```css
/* Brand */
--khu-red:   #A40F16;   /* 포인트: 로고, 활성 탭, 주 버튼 */
--khu-blue:  #0D326F;   /* 링크, 헤더 텍스트, 정보 배지 */
--khu-gold:  #C0A353;   /* D-day, 마감 임박 강조 */
--khu-gray:  #717171;   /* 메타 텍스트 */
--khu-silver:#B5B5B5;   /* 구분선, 비활성 */

/* Surface */
--bg:        #F7F7F8;
--card:      #FFFFFF;
--text:      #333333;
--border:    #E6E6E8;

/* Type */
font-family: 'Noto Sans KR', 'Roboto', system-ui, sans-serif;  /* 숫자/영문은 Roboto가 우선 적용되도록 unicode-range 처리 */
제목 15~16px/600, 본문 14px/400, 메타 12px/400
```

| 국제 | #E3EEF8 | #1C5B8E |

조직 배지(캠퍼스·단과대·학과)는 색 없이 **회색 외곽선(outline)** 으로 통일해 주제 배지와 시각적으로 구분한다.
출처 유형은 배지가 아니라 **아이콘**(🌐 웹 / Instagram 글리프)으로만 표시한다.

## 3. 화면 구조

### 3.1 온보딩 (최초 1회, 3단계)

```text
[1/3] 캠퍼스     ( 서울 ) ( 국제 )
[2/3] 단과대     리스트(검색 가능)
[3/3] 학과       리스트(검색 가능)   [건너뛰기]
→ "이제 정경대·행정학과 공지를 놓치지 않아요"  [시작하기]
```

건너뛰면 `전체 공지`로 진입하고, 헤더의 "내 학과 설정" 배너가 남는다.

### 3.2 헤더 (모든 화면 공통, 상단 고정)

```text
┌──────────────────────────────────────────────┐
│ 경희공지        [서울 ▾]        🔍   ⚙       │
├──────────────────────────────────────────────┤
│  내 공지  ·  전체  ·  출처                    │  ← 활성 탭 밑줄 Red
└──────────────────────────────────────────────┘
```

- 로고: 텍스트 워드마크 "경희공지"(Red). 공식 휘장·교표는 쓰지 않는다. 필요 시 사자 캐릭터 실루엣을 보조 아이콘으로 검토(비공식 표기 필수).
- 캠퍼스 토글은 헤더에 항상 노출. 서울/국제 학생이 서로 섞인 공지에서 가장 먼저 걸러내고 싶은 축이기 때문.
- 검색은 제목·본문 전문 검색(PostgreSQL FTS) 화면으로 이동.

### 3.3 내 공지 (홈)

```text
┌ 마지막 방문 이후 새 공지 7건 ────────── [맨 위로] ┐   ← Blue 배경, 닫기 가능

┌ ⏰ 마감 임박 ────────────────── 가로 스크롤 ┐
│ [D-2] 국가장학금 2차 신청  │ [D-5] 교환학생 … │   ← Gold 테두리 미니 카드
└──────────────────────────────────────────┘

[전체] [학사] [장학] [취업·인턴] [행사] [프로그램] … ▸   ← 주제 칩, 다중선택, 가로 스크롤

┌──────────────────────────────────────────────┐
│ 2026-2학기 학점포기 신청 안내                    │  ← 제목, 미읽음은 좌측 Red 점
│ [학사] ⌜정경대⌟                                │  ← 주제 배지 + 조직 outline
│ 정경대학 · 9월 3일 · 🌐 · 동일 공지 3곳          │  ← 메타(Gray)
└──────────────────────────────────────────────┘
┌──────────────────────────────────────────────┐
│ [포스터 썸네일] 2026 대동제 부스 모집             │  ← Instagram 카드는 좌측 정사각 썸네일
│ [행사] ⌜총학생회⌟                               │
│ 서울캠퍼스 총학생회 · 9월 5일 · ◎ Instagram      │
└──────────────────────────────────────────────┘
        ┌───────── 광고 (라벨 명시) ─────────┐   ← 카드 10~15장마다 1개, 카드 폭과 동일
```

- 정렬: 게시일 내림차순. "마감 임박"만 별도 섹션.
- 카드 탭 → 상세 시트(본문 텍스트 + 첨부 + 출처 목록 + [원문 보기]). Instagram은 caption/OCR 텍스트 + [Instagram에서 보기].
- 카드 길게 누르기/메뉴 → "이 출처 숨기기", "북마크".
- 동일 공지 N곳: 클러스터 카드 하나로 보여주고 상세에서 출처 4개를 리스트로 펼친다.

### 3.4 전체 공지

내 공지와 동일한 카드 피드. 차이는 상단에 **조직 필터 바**가 추가된다.

```text
[서울 ▾] [단과대 ▾] [학과 ▾] [기관·사업단 ▾]      ← 드롭다운 4개 + 활성 필터 칩 표시/제거
```

### 3.5 출처

기획서 5.1의 조직 트리를 그대로 탐색·구독하는 화면.

```text
경희대학교
├ 서울캠퍼스            구독 12 / 전체 96
│ ├ 정경대학  ▸
│ │ ├ 행정학과 홈페이지      🌐  ● 15분 전     [구독중]
│ │ └ 행정학과 학생회        ◎  ● 2시간 전     [구독]
│ ├ 미래인재센터              🌐  ● 15분 전     [구독중]
```

- 각 소스 행: 이름, 출처 유형 아이콘, 마지막 수집 시각(수집 상태 점: 초록/회색/빨강), 구독 토글.
- 소스 탭 → 그 소스의 공지만 보는 피드.
- 상단 검색으로 "SW중심대학" 같은 기관을 바로 찾는다.

### 3.6 설정 (⚙)

캠퍼스/단과대/학과 변경, 구독 목록, 숨긴 출처, 알림(추후: 웹 푸시), 다크모드(추후), 서비스 소개·비공식 안내·문의.

## 4. 데스크톱 레이아웃 (≥1024px)

```text
┌ 헤더 (동일) ─────────────────────────────────────────────────┐
│ 좌측 240px         │ 중앙 피드 (max 720px)     │ 우측 280px  │
│ 조직 트리/구독     │ 새 공지 배너 + 칩 + 카드    │ 마감 임박   │
│ 주제 체크박스       │                           │ 광고 1개    │
└───────────────────────────────────────────────────────────┘
```

모바일에서 가로 스크롤이던 "마감 임박"과 필터가 좌우 컬럼으로 펼쳐질 뿐, 카드 컴포넌트는 동일하다.

## 5. 상태 · 엣지 케이스

- 빈 피드(구독 없음): "학과를 설정하면 여기에 공지가 모여요" + [학과 설정] 버튼.
- 수집 실패 소스: 출처 화면에 빨간 점 + "3일째 수집 실패". 피드에는 조용히 빠진다.
- 마감일 추출 실패: D-day 표시 안 함(기획서 16장 원칙). 절대 잘못된 D-day를 보이지 않는다.
- 본문 없이 첨부만 있는 공지: 카드에 📎 아이콘과 파일명.
- 아주 긴 제목: 2줄 말줄임.

---

## 6. 구현 스택 제안

- 프론트: Next.js(App Router) + Tailwind, 토큰은 위 CSS 변수. SSR로 첫 피드를 빠르게.
- 상태: localStorage(설정/읽음/구독) → 추후 계정 동기화.
- 아이콘: Lucide. 폰트: Google Fonts Noto Sans KR + Roboto.
- 광고: 초기엔 자체 배너 1슬롯 컴포넌트만 두고 네트워크 연동은 뒤로.
