## 완료한 적용

1. 수집 예약을 잠시 정지하고 수정 코드를 기본 브랜치에 게시했다.
2. 기존 백업 실패 원인이 데이터베이스 17버전과 백업 도구 16버전의 불일치임을 확인했다. 공식 패키지 저장소의 17버전 클라이언트를 사용하도록 수정했다.
3. 사용자의 명시적 승인 후 기존 비공개 백업 버킷에 암호화 백업을 생성했다. 내려받기·해시·복호화·압축 해제·스키마 포함 검사가 통과했다. 별도 데이터베이스에 전체 복원하는 검사는 수행하지 않았다.
4. 운영 데이터베이스가 0001임을 확인하고 0002 구조 변경을 적용했다. 변경 작업의 적용 후 결과와 별도 읽기 전용 조회에서 0002를 확인했다.
5. 기존 계정에 조회 서버가 없음을 확인하고 공개 JSON 버킷만 연결한 조회 서버를 배포했다. 원문 증거·백업 버킷은 연결하지 않았다.
6. 실제 조회에서 압축 JSON의 중복 압축 문제를 발견했다. 저장소 압축을 스트림으로 해제한 뒤 런타임이 전송 압축을 처리하도록 수정했다. 최초 요청·캐시 요청의 실제 런타임 검사가 통과했고 운영에서도 JSON 파싱을 확인했다.
7. 수집 예약을 다시 활성화하고 대표 출처 수집을 실행했다.
